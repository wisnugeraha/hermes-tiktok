What the app does

Hermes is the owner’s personal automation assistant. The owner gives Hermes instructions (for example, “post this video tomorrow at 7pm” or “show me my recent videos and their view counts”), and Hermes carries them out on the owner’s own TikTok account through this app. Every action is initiated by the owner and can be revoked by the owner at any time in TikTok’s settings.

Sign in with TikTokLogin Kit · user.info.basic

The owner authorizes Hermes TikTok through TikTok’s standard OAuth 2.0 flow with PKCE. The app receives the owner’s open ID, display name, and avatar — only enough to confirm which account is connected.

View your own videosLogin Kit · video.list (Display API endpoints)

Hermes can list the owner’s own videos and display their titles, cover images, and public engagement counts back to the owner, so the owner can review what is live on their account and plan follow-up content. On TikTok’s platform the Display API is not a separate product — its endpoints are enabled through Login Kit together with the video.list scope.

Publish your videosContent Posting API · video.publish

When the owner asks Hermes to post, the app uploads the owner’s own video file and publishes it to the owner’s own account as a Direct Post, with the title and privacy level the owner specified.

Send to inbox for finishingContent Posting API · video.upload

Alternatively, Hermes can upload a video to the owner’s TikTok inbox, where the owner reviews, edits, and publishes it manually in the TikTok app. Nothing is published without the owner’s final action in this mode.

How authorization works

The full end-to-end flow a reviewer can reproduce:

  1. Hermes generates an authorization link

    Hermes builds a TikTok Login Kit authorization URL with a PKCE code challenge and a random state value, and sends the link to the owner.

  2. The owner approves on TikTok

    The owner opens the link, signs in to TikTok, reviews the requested scopes, and approves. The owner can decline or revoke access at any time.

  3. TikTok redirects back to this website

    TikTok redirects the owner’s browser to this website’s plain address — the registered redirect URI, with no fragment — carrying a one-time authorization code in the query string (?code=…). The site detects the code as soon as the page loads and immediately shows the authorization-code view with the code and a copy button, so the owner can copy it and send it back to Hermes.

  4. Hermes exchanges the code for tokens

    Hermes exchanges the code (with its PKCE verifier) for an access token and refresh token, stored only on the owner’s own Hermes instance. Hermes then calls the Display API endpoints (via Login Kit) and the Content Posting API on the owner’s behalf, and checks posting status until TikTok confirms the result.

Scope honesty: TikTok’s official APIs do not offer endpoints for posting comments or liking content on behalf of a user, so Hermes TikTok does not request those capabilities and does not automate them in any other way. The app only uses the products and scopes listed on this page.

WHAT THE APP IS
Hermes TikTok is a personal, single-user integration. The user is the developer/account owner himself. Hermes is the owner's personal assistant; this app lets Hermes act on the owner's own TikTok account, at the owner's explicit request, using only TikTok's official APIs. There is no public sign-up, no multi-user service, no advertising, and no data is collected from any third party.

HOW EACH PRODUCT AND SCOPE IS USED

1) Login Kit — scope: user.info.basic
Hermes generates a Login Kit authorization URL using OAuth 2.0 with PKCE (code challenge + state). The owner opens the link, signs in to TikTok, reviews the scopes, and approves. TikTok redirects the owner's browser to our redirect URI — the plain website address registered in the portal (TikTok rejects redirect URIs containing a fragment) — with a one-time authorization code in the query string (?code=...). On page load the website detects the code automatically and displays it, with a copy button, so the owner can copy it and send it back to Hermes. Hermes then exchanges the code together with the PKCE verifier for an access token and refresh token. user.info.basic is used only to confirm the connected account's identity (open ID, display name, avatar) so the owner can verify the right account is linked. Tokens are stored only on the owner's own Hermes instance, are never shared, and access can be revoked by the owner at any time in TikTok settings.

2) Display API endpoints, enabled via Login Kit — scope: video.list
Note: on TikTok's platform the Display API is not a separate product; its endpoints are enabled through Login Kit together with the video.list scope. After authorization, Hermes queries the Display API's video list and query endpoints to list the owner's own videos (title, cover image, create time, and public engagement counts such as views, likes, comments, and shares). The results are shown only to the owner, so the owner can review what is currently published on their own account and decide what to post next. No other user's videos or data are accessed.

3) Content Posting API — scope: video.publish (Direct Post)
When the owner instructs Hermes to publish a video, Hermes uploads the owner's own video file through the Content Posting API and creates a Direct Post on the owner's own account, using the title and privacy level the owner specified. Hermes then polls the posting status endpoint until TikTok confirms the post is published or reports a failure, and reports the result back to the owner.

4) Content Posting API — scope: video.upload (Upload to inbox)
As an alternative the owner can choose, Hermes uploads the owner's video to the owner's TikTok inbox instead. The video is not published by the API in this mode; the owner reviews, edits, and publishes it manually inside the TikTok app.

END-TO-END FLOW (for the demo video)
1. Hermes creates the authorization link and sends it to the owner.
2. The owner opens the link, logs in to TikTok, and approves the requested scopes.
3. TikTok redirects to the plain website address (the redirect URI) with the authorization code in the query string; the website detects the code on load and displays it automatically, and the owner copies it and sends it to Hermes.
4. Hermes exchanges the code for tokens and fetches the owner's profile (user.info.basic).
5. Hermes lists the owner's recent videos via the Display API endpoints (Login Kit, video.list) and shows them to the owner.
6. The owner asks Hermes to post a video; Hermes publishes it via Direct Post (video.publish) — or uploads it to the inbox (video.upload) — and confirms the final status to the owner.

DATA HANDLING SUMMARY
Data accessed is limited to the owner's own account data returned by the scopes above. It is processed only to carry out the owner's instructions, is stored only on the owner's own systems, is never sold or shared with third parties, and is deleted when the owner revokes access or asks for deletion. Full details are in the Privacy Policy on this website.

NOTES
- The app does not use, and does not request, any capability TikTok does not officially offer. In particular, comments and likes are not automated, because TikTok provides no official API endpoints for them.
- All API calls are made server-to-server by Hermes after the owner completes the OAuth flow; the website itself is static and stores no tokens or user data.

Privacy Policy

Hermes TikTok · Last updated: 25 November 2026

1. Who this policy covers

This policy explains how Hermes TikTok (“the App”), operated by the Hermes developer organization, handles data when the owner of a TikTok account (“you”) connects that account to the Hermes personal assistant. The App is a personal, single-user integration: it only ever accesses the connected owner’s own TikTok data.

2. Data the App accesses

Through TikTok’s official APIs, and only within the scopes you approve, the App accesses:

  • Basic profile data (scope user.info.basic): your TikTok open ID, display name, and avatar URL — used to confirm which account is connected.
  • Your video list (scope video.list): identifiers, titles, cover images, creation times, and public engagement counts (views, likes, comments, shares) of your own videos — shown back to you so you can review your account.
  • Videos you ask us to post (scopes video.publish and video.upload): the video file, title, and privacy level you provide for a specific post or inbox upload, sent to TikTok to carry out that instruction.
  • Authorization tokens: the OAuth access token and refresh token issued by TikTok when you authorize the App, plus posting-status results returned by TikTok for your uploads.

The App does not access your TikTok password, direct messages, followers’ private data, or any data of accounts other than your own. This website is static: it collects no analytics, sets no tracking cookies, and stores nothing. The authorization callback page displays the authorization code in your own browser only, so you can copy it; the code is not sent to or stored by this website.

3. How data is used

  • To carry out your instructions: showing you your profile and videos, and publishing or uploading videos you asked to post.
  • To confirm posting results (published, processing, or failed) and report them back to you.
  • For no other purpose. Your data is never sold, never used for advertising, and never shared with third parties, except TikTok itself as required to perform the API calls you requested.

4. Storage and security

  • Access and refresh tokens are stored only on the owner’s own Hermes system, in access-restricted storage, and are never printed in logs or shared in chat or email.
  • Video files are transmitted to TikTok for the post you requested and are not retained by the App after TikTok confirms the final posting status, except where you keep your own copies in your own storage.
  • Profile and video-list responses are processed to answer your request and are not built into any profile of you and are not retained longer than needed to display them to you and keep a basic activity record on your own system.

5. Your choices and rights

  • Revoke access: you can disconnect the App at any time in TikTok’s settings (Settings → Security → Apps and websites, or the equivalent current path). Revocation immediately ends the App’s ability to call TikTok’s APIs for your account.
  • Deletion: on revocation, or at any time on your request to the contact below, stored tokens are deleted and any retained account data on the Hermes system is erased.
  • Access and correction: the data the App holds about you is your own TikTok data, which you can view and correct directly in TikTok.

6. Children

The App is intended solely for the adult account owner who operates it and is not directed at children. It does not knowingly collect data about children.

7. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new revision date. Material changes to what data is accessed would require new scopes, which TikTok would present to you for approval before any access occurs.

8. Contact

Privacy questions or deletion requests can be sent to the Hermes developer organization through the contact details listed in the TikTok for Developers portal for this app (App ID 7712031353398921237).
