# Hermes TikTok — App Website

Website for the "Hermes TikTok" TikTok developer app (owner: @moongarms7).
Used as the app's Web/Desktop URL, Terms of Service and Privacy Policy
pages in the TikTok developer portal, plus the OAuth callback page.

- Login Kit (user.info.basic, video.list)
- Content Posting API (video.upload, video.publish)

The file `tiktokng6nmb0wn9RGkqAnOcqLmYAa4TvFTIYr.txt` is TikTok's
URL-ownership verification file and must stay at the site root.
